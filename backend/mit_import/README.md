# Learnly MIT 6.189 Import Bundle

Course: 6.189 A Gentle Introduction to Programming Using Python (January IAP 2008)
Source: MIT OpenCourseWare
Source URL: https://ocw.mit.edu/courses/6-189-a-gentle-introduction-to-programming-using-python-january-iap-2008/
License: CC BY-NC-SA 4.0 (verify the current MIT OCW terms before commercial use)

This bundle contains the course metadata and educational resource files from the uploaded OCW course ZIP. It does not contain lecture video files; the imported lecture records therefore use reading/resource links rather than fabricated video URLs.

IMPORTANT: Put `import_mit_course.py` into `backend/`, keep the extracted `mit_course_resources` and `manifest.json` next to it, then run it from the backend virtual environment.
